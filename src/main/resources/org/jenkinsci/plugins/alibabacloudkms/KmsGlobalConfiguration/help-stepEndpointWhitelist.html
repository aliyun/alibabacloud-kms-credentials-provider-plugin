Comma-separated host patterns that the endpoint argument of withAlibabaCloudKms must match, for example *.aliyuncs.com,kms.internal.example.com. * matches any run of characters, dots included; everything else is literal, and matching is case-insensitive. Leave empty for the default, *.aliyuncs.com.

Naming an endpoint is the one part of a KMS call a pipeline author controls with Job/Configure alone, so without this limit a job could make the controller open a connection to a host of its choosing, signed with the controller's own Alibaba Cloud identity, and read that host's reply back through the build log. The Endpoint above is not covered: setting it already takes Overall/Administer, as do the environment variable and system property that override it. A step that leaves its own endpoint empty inherits the global one and so is not checked either.

Widen it only as far as your pipelines require: an exact host name is stricter than a pattern, and * on its own switches the check off. It bounds which host the controller contacts first, not where that host may redirect it — the Alibaba Cloud SDK follows redirects and offers no switch to stop it. Can also be set with the ALIBABA_CLOUD_KMS_STEP_ENDPOINT_WHITELIST environment variable or the jenkins.alibabacloud-kms.stepEndpointWhitelist system property, which take precedence.
